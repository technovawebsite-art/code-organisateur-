# Organisateur de fichiers Python

Une petite application avec interface graphique qui analyse un dossier et range
automatiquement ses fichiers dans les catégories Images, Vidéos, Documents,
Audio, Archives, Programmes et Autres.

## Utilisation

1. Installez Python 3.
2. Téléchargez `organisateur.py`.
3. Lancez `python organisateur.py`.
4. Choisissez un dossier et vérifiez la prévisualisation.
5. Cliquez sur **Ranger les fichiers**, puis confirmez.

Le programme n'écrase jamais un fichier existant : il ajoute un numéro au nom
si nécessaire.
